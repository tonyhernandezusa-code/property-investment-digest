PROPERTY INVESTMENT DIGEST — MIGRATION 8.3 BUYER BROKERAGE / COMMISSION

UPLOAD
1. Download and unzip property-investment-digest-migration8-3-buyer-brokerage.zip.
2. Open the property-investment-digest GitHub repository.
3. Click Add file > Upload files.
4. Select every file inside the extracted Migration 8.3 folder.
5. Drag the files into GitHub.
6. Commit message:
   Add buyer brokerage cash to close
7. Click Commit changes.
8. Wait for Pages build and deployment.

NO GOVERNMENT DATA UPDATE IS REQUIRED.
