PROPERTY INVESTMENT DIGEST — MIGRATION 3

This package adds a private browser-based Property Manager.

UPLOAD:
1. Download and unzip property-investment-digest-migration3.zip.
2. Open the existing property-investment-digest GitHub repository.
3. Click Add file > Upload files.
4. Select every file inside the unzipped Migration 3 folder.
5. Drag them into GitHub.
6. Commit message:
   Add private property manager
7. Click Commit changes.
8. Wait for the Pages deployment green check.
9. Open:
   https://tonyhernandezusa-code.github.io/property-investment-digest/property-manager.html
10. Press Ctrl + F5.
