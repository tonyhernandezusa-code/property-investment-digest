NO NEW SECRET OR WORKFLOW FILE IS REQUIRED.
The existing Update Government Data workflow and CENSUS_API_KEY are reused.

UPLOAD:
1. Download and unzip property-investment-digest-migration7.zip.
2. Open the property-investment-digest GitHub repository.
3. Click Add file > Upload files.
4. Select every file inside the unzipped Migration 7 folder.
5. Drag the files into GitHub.
6. Commit message:
   Add HUD rents and FEMA declarations
7. Click Commit changes.
8. Wait for Pages build and deployment.

RUN THE UPDATE:
1. Click Actions.
2. Select Update Government Data.
3. Click Run workflow.
4. Confirm branch main.
5. Click the green Run workflow button.
6. Wait for the green check.
7. Wait for Pages deployment.
8. Open:
   https://tonyhernandezusa-code.github.io/property-investment-digest/rent-disaster.html
9. Press Ctrl + F5.
