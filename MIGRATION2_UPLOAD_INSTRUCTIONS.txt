PROPERTY INVESTMENT DIGEST — MIGRATION 2

This package expands the property calculators while retaining the protected county map.

UPLOAD:
1. Download and unzip property-investment-digest-migration2.zip.
2. Open the existing property-investment-digest GitHub repository.
3. Click Add file > Upload files.
4. Select every file inside the unzipped Migration 2 folder.
5. Drag them into GitHub.
6. Commit message:
   Add full property calculators
7. Click Commit changes.
8. Wait for the Pages deployment green check.
9. Open:
   https://tonyhernandezusa-code.github.io/property-investment-digest/calculator.html
10. Press Ctrl + F5.
